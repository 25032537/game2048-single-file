# 2048 · 单文件网页小游戏

一个零依赖的单文件 2048 小游戏，纯 HTML + CSS + 原生 JavaScript，所有样式与脚本内联在一个 `index.html` 里，直接双击即可运行，也可托管在任意静态服务器上。

![2048](https://img.shields.io/badge/2048-single--file-3ba7ff)

## 功能

- **4×4 网格**，经典 2048 玩法
- **键盘操作**：方向键 ↑ ↓ ← →
- **WASD 操作**：桌面端备选方案
- **触屏滑动**：手机上直接滑动屏幕
- **鼠标拖拽**：桌面端也能拖拽操作
- **相同数字合并翻倍**，每次有效移动后随机生成 2（90%）或 4（10%）
- **无法合并时自动判定 Game Over**
- **实时分数** + **历史最高分**（`localStorage` 持久化）
- **响应式适配**：手机、平板、桌面自适应，网格尺寸随视口缩放
- **成绩分享**：调用原生分享 API，不支持时降级为复制到剪贴板

## 技术要点

| 项目 | 说明 |
|---|---|
| 依赖 | **无**。不使用 npm、Vite、Webpack 或任何 CDN |
| 构建 | **无需构建**，单文件直接部署 |
| 体积 | 约 13 KB |
| 兼容性 | 现代浏览器（Chrome / Edge / Safari / Firefox） |
| 存储 | `localStorage` 保存最高分，失败时静默降级 |

### 实现细节

- 棋盘状态是一个 4×4 的二维数组，空格用 `0` 表示
- 移动逻辑统一为"向左合并"：向上/下先把列转成行，向右则先反转行，处理完再还原，避免四份重复代码
- 合并规则：同一行内相邻且相等的数字合并成双倍，**每个数字单次移动最多参与一次合并**（`[2,2,2,2]` → `[4,4]`，不是 `[8]`）
- 渲染用 `documentFragment` 一次性重建瓦片，位置按容器实测像素计算，因此窗口缩放也不会错位
- 瓦片配色按数值分级（2 到 2048 十一档），超过 2048 使用统一的紫色

## 运行

### 方式一：直接打开

```bash
# 双击 index.html，或者
start index.html      # Windows
open index.html       # macOS
```

### 方式二：本地静态服务器

```bash
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/index.html
```

### 方式三：托管到云

任意静态托管均可，例如把 `index.html` 放到 Nginx 的站点目录：

```bash
mkdir -p /usr/share/nginx/html/hc-activity
cp index.html /usr/share/nginx/html/hc-activity/index.html
```

## 玩法提示

1. 尽量把最大的数字固定在一个角落，不要来回移动它
2. 保持一行或一列处于"排满"状态，只用另外三个方向操作
3. 优先做大规模合并，避免零散的小数字堵死棋盘
4. 急于合并反而容易失控，必要时先铺开再收拢
